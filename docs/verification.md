# 0.1.0 验证记录

验证环境：2026-10-05，Windows，Python 3.12、Node 24、pnpm 11、Tauri 2。本机开发数据与隔离验证数据使用不同目录。

## 已验证

- 后端：28 项自动测试通过。覆盖认证、密钥不回显、记忆保存/确认/删除、图片校验和图片能力开关、不同主题课程、原子校验、课程不覆盖、checkpoint 重启恢复、练习失败重试、跳过、真实 LangChain 工具循环、对话创建学习框架、流式事件、取消与重试、搜索与正文适配、JSON 修复上限、错误信息脱敏。
- 前端：3 项 Vitest 测试通过，覆盖中文跨字节 SSE 分片、keepalive、可读错误信息。
- 浏览器：6 个端到端场景全部通过，覆盖小窗口文字可见、接口设置、新对话与工具记忆、课程/教学/反馈/刷新恢复、记忆增改删、提醒增改与完成。使用本地模拟接口，无真实 API 请求。
- `pnpm api:types`、`pnpm build`、`cargo check` 通过。前端构建有单个 JavaScript chunk 大于 500 kB 的优化提示，不影响本机功能。
- 首页 axe 检查：0 个发现的违规项。未将首页结果扩展为整个应用的无障碍认证。
- Windows 系统凭据存储：使用独立测试条目验证写入、读取、删除，不访问用户已有密钥。
- 原生 Tauri：实际 WebView2 使用原生 IPC；读取保存的练习通过状态；关闭主窗口后仍弹出独立提醒窗口；点击「知道了」将通知保存为已读。退出应用后它自己启动的后端端口释放，再启动仍能读取课程和反馈。
- 启动脚本：后台启动正常桌面空间成功；正常空间无模拟课程、对话或测试提醒，模型和搜索均待用户配置。测试数据单独保留。
