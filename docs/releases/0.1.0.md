# Bai Agent 0.1.0

交付日期：2026-10-16。Windows x64，采用用户选定的 A 版「奶油方糖」图标。

## 安装包

- 文件：`releases/0.1.0/Bai-Agent_0.1.0_x64-setup.exe`
- 大小：36,241,350 字节，约 34.6 MiB。
- SHA-256：`E735049B30DBC64281C7B3F9854C823942A405F2007DF8367DE89623E4836A6D`
- 安装器及程序的 Windows 文件版本均为 `0.1.0.0`；两者的嵌入图标均核对为 A 版。安装器未作代码签名。
- 包含内嵌前端、独立 Python 3.12 后端、依赖与数据库迁移；无需目标机器提供 Python、Node.js、pnpm、uv 或 Rust。目标机需有 WebView2，缺少时 NSIS 联网安装。

安装版默认将数据保存在 `%LOCALAPPDATA%\com.qinbai.baiagent`，密钥仍保存在 Windows 凭据管理中。安装目录只保存程序与依赖，后端诊断日志写入数据目录。安装包不包含开发版的个人数据库、图片、API 密钥或测试记录。

开发版仍通过项目中的启动器运行。开发版与安装版默认数据目录独立；退出已有 Bai 后再启动另一个空间，避免同时占用 8766 端口。

## 本版内容

- 奶油杏主题、大圆角界面、可收起侧栏与克制的辅助文案。
- 平面小精灵，默认眼神按用户参考图；支持眨眼、呼吸、鼠标跟随与受限的正确透视。
- 简化的对话工具入口、持久化工具结果、自动增高的输入框。
- 课程目录、进度、教学和练习阅读区调整。
- 长期记忆自动保存普通稳定偏好；私密或推测信息确认后生效，支持撤销、来源、编辑删除及每次确认模式。
- 天气、搜索、网页阅读、计算、日期、单位、记忆、提醒和学习工具。
- Windows 自包含 NSIS 安装包与可重复构建脚本。

## 构建

```powershell
pnpm install --frozen-lockfile
uv sync --project backend --frozen
pnpm release:windows
```

`scripts/build-installer.ps1` 调用 release 配置，先构建前端和 PyInstaller onedir 后端，再生成当前用户安装的中英文 NSIS 安装器，复制至 `releases/<version>/` 并写入校验文件。重复构建会先备份并验证已有交付安装包。开发配置不要求已有封装后端。

资源定位按 [Tauri 资源目录](https://v2.tauri.app/develop/resources/) 配置；后端入口与迁移随 [PyInstaller spec](https://pyinstaller.org/en/stable/spec-files.html) 封装。
