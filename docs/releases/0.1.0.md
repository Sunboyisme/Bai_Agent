# Bai Agent 0.1.0

交付日期：2026-10-16。Windows x64，采用用户选定的 A 版「奶油方糖」图标。

## 安装包

- 文件：`releases/0.1.0/Bai-Agent_0.1.0_x64-setup.exe`
- 大小：36,247,800 字节，约 34.6 MiB。
- SHA-256：`C92DBF5BBABFDF7EB1077145C6BE060F77F9C2E4B555D6CB6EA751186BA66B2C`
- 安装器及程序的 Windows 文件版本均为 `0.1.0.0`；两者的嵌入图标均核对为 A 版。安装器未作代码签名。
- 包含内嵌前端、独立 Python 3.12 后端、依赖与数据库迁移；无需目标机器提供 Python、Node.js、pnpm、uv 或 Rust。目标机需有 WebView2，缺少时 NSIS 联网安装。

安装版默认将数据保存在 `%LOCALAPPDATA%\com.qinbai.baiagent`，密钥仍保存在 Windows 凭据管理中。安装目录只保存程序与依赖，后端诊断日志写入数据目录。安装包不包含开发版的个人数据库、图片、API 密钥或测试记录。

开发版仍通过项目中的启动器运行。开发版与安装版默认数据目录独立；优先使用 8766 端口，被其他数据空间或程序占用时自动选择可用端口。只有通过当前数据目录令牌认证的已有 Bai 服务才会复用，界面和提醒均连接实际选定的端口。

## 安装后无法打开的修复

初始安装包在 8766 端口已有其他 Bai 数据空间运行时，启动钩子返回错误，桌面程序以 101 退出，没有显示可用窗口。已在 `C:\APP\Bai Agent` 的原安装程序上捕获并复现；原发布验证使用隔离端口，漏掉了默认端口冲突场景。

修复后自动选择可用端口；在启动子进程前保留端口，防止界面和后端选择不同地址。三个 Rust 回归测试覆盖空闲端口预留与释放、其他服务占用、同一空间服务复用。原生检查分别覆盖其他 Bai 服务占用、普通 HTTP 服务占用、同一空间服务复用，均从内嵌页面通过 IPC 连接后端，七个认证接口返回成功，无检查期间页面脚本错误；退出应用没有关闭不属于它的服务。

已备份原安装目录，再用修正版 NSIS 实际更新 `C:\APP\Bai Agent`。安装后的程序除 Tauri 的 NSIS 类型标记外与修复构建一致；在不覆盖后端端口或数据目录的情况下成功打开，自动使用 62248 端口，与仍占用 8766 的开发后端共存。正常安装数据目录令牌和 IPC 返回的令牌一致，七个本机接口通过认证检查。用户已在设置页操作，因此保留窗口，本轮未重新启动这个正常数据空间，也没有改动模型配置或调用真实模型。

修正版仍为 0.1.0。初始安装包已归档至交付目录的时间戳子目录；原 Git 标签 `v0.1.0` 保留，修复源代码另存为 `v0.1.0-fix.1`。本轮证据和程序备份在 `.local-data/startup-repair/`，均不进入 Git。

## 本版内容

- 奶油杏主题、大圆角界面、可收起侧栏与克制的辅助文案。
- 平面小精灵，默认眼神按用户参考图；支持眨眼、呼吸、鼠标跟随与受限的正确透视。
- 简化的对话工具入口、持久化工具结果、自动增高的输入框。
- 课程目录、进度、教学和练习阅读区调整。
- 长期记忆自动保存普通稳定偏好；私密或推测信息确认后生效，支持撤销、来源、编辑删除及每次确认模式。
- 天气、搜索、网页阅读、计算、日期、单位、记忆、提醒和学习工具。
- Windows 自包含 NSIS 安装包与可重复构建脚本。

## 构建

```powershell
pnpm install --frozen-lockfile
uv sync --project backend --frozen
pnpm release:windows
```

`scripts/build-installer.ps1` 调用 release 配置，先构建前端和 PyInstaller onedir 后端，再生成当前用户安装的中英文 NSIS 安装器，复制至 `releases/<version>/` 并写入校验文件。重复构建会先备份并验证已有交付安装包。开发配置不要求已有封装后端。

资源定位按 [Tauri 资源目录](https://v2.tauri.app/develop/resources/) 配置；后端入口与迁移随 [PyInstaller spec](https://pyinstaller.org/en/stable/spec-files.html) 封装。
