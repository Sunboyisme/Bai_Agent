# 小汐 0.1.1

交付日期：2026-10-17。Windows x64，自包含 NSIS 安装包。

## 安装包

- 文件：`releases/0.1.1/小汐_0.1.1_x64-setup.exe`
- 大小：45,509,901 字节，约 43.40 MiB。
- SHA-256：`A96E3CA23C557F96A36CA7CBFE2C63AF4E1BAE84D1480DC8F43B391FF40EC5C9`
- 安装器、桌面程序、前端及后端版本统一为 `0.1.1`，Windows 数值文件版本为 `0.1.1.0`。安装器未作代码签名。
- 内含前端、Python 3.12 后端、MCP 依赖及数据库迁移，无需目标机器安装 Python、Node.js 或 Rust。第三方 stdio MCP 服务所需的命令及运行环境需另行准备；缺少 WebView2 时安装器会联网下载。

安装标识与默认数据目录仍为 `com.qinbai.baiagent`，配置密钥使用 Windows 凭据管理器，沿用现有数据兼容方式。此次构建没有覆盖个人安装目录或数据库，原 0.1.0 安装包保持原状。

## 本版内容

- 应用更名为「小汐」，保留原启动入口与数据目录兼容。
- 设置拆分为连接、工具、记忆三个页签；完整记忆管理移入设置。
- 统一管理内置工具与 MCP 服务，支持 stdio、Streamable HTTP、Header/环境变量凭据、JSON 导入预览、连接测试与工具开关。
- MCP 新工具默认关闭；已启用且可用的工具自动提供给 Agent，关闭后执行前再次拦截。调用记录保留来源、状态及摘要。
- 本机微信文字渠道、绑定与提醒开关默认关闭；实际手机收件仍需用户自行绑定验收。

接入步骤见 [MCP 操作说明](../mcp.md)，微信说明见 [本机微信渠道](../wechat-integration.md)。

## 重复构建

```powershell
pnpm install --frozen-lockfile
pnpm release:windows
```

构建脚本同步锁定的后端依赖、封装前后端，再生成 NSIS 安装包并复制到 `releases/<version>/`，写入 `SHA256SUMS.txt`。同版本已有交付文件时先归档并验证备份。
