# Bai 的奶油杏界面

采用用户于 2026-10-16 选定的「奶油杏」方案：大圆角、暖奶油底色、杏桃色强调和圆润的小精灵形象。基础结构在 `src/style.css`，当前主题在 `src/styles/cream.css`，由 `src/main.tsx` 按此顺序加载。`src/styles/interface.css` 是先前的外观文件，当前不加载。

## 字体与外观

- 正文字体使用 `"Microsoft YaHei UI", "PingFang SC", system-ui, sans-serif`，不加载联网字体。正文 16px、控件 14px、辅助信息 12px，中文保持正常字距。
- 代码使用系统等宽字体栈，Windows 优先使用 Consolas。
- 页面底色 `#f6efe8`，工作区 `#fffcf8`，主要文字 `#433b35`，辅助文字 `#766a60`，主要操作 `#a95940`。
- 工作区圆角 32px、输入区 28px、普通卡片 24px、控件 16px。导航与重要操作保持充足点击面积，菜单与弹窗沿用同一语言。
- 新对话按「问候 → 输入 → 学习与提醒」排列，内容较高时整块首页滚动；已有对话将输入区保留在底部，消息区单独滚动。学习页保留课程目录与阅读区。
- 根据用户截图批注，移除了顶部面包屑、「本机空间」标签、首页四张工具卡片、左下角个人信息及接续区右侧的辅助短句；保留右上角提醒入口。
- 首页展示真实的最新学习目标、练习通过数与最早的有效提醒；无记录时提供创建入口。点击学习卡片会选中对应目标；不包含提案中的示例数据。
- 文案保持克制：移除首页问候副句、底部短句、输入区自动保存说明，以及提醒页的常驻时区与托盘说明。错误反馈、处理状态和表单必要信息继续按操作出现，避免重复的常驻引导。
- 学习课程使用独立顶部标题与进度、可收起目录和居中阅读区。目录按模块分组，以序号及完成状态展示知识点，不为每项重复标注“未开始”。开始按钮紧接学习目标；生成中显示轻量占位；讲解与练习连续阅读，底部提供跳过和上一节／下一节操作。小窗口默认收起目录，需要时通过“目录”按钮展开。
- `BaiAvatar.tsx` 按用户选定的平面 A 版实现杏陶色渐变圆球与奶白色眼睛。选定原图保存在 `docs/assets/bai-avatar-a-reference.png`，运行时使用独立眼睛的 SVG 与 CSS 动效，不新增依赖。每个头像使用独立渐变 ID，适配首页和小尺寸聊天头像。
- 侧栏和首页轻微呼吸、约 7.8 秒眨眼一次；鼠标悬停或键盘聚焦侧栏头像时轻轻歪头，按下时略微压扁。回答生成中使用轻摆，历史消息头像静止。系统设置减少动态效果时关闭头像动画和悬停位移。
- 侧栏、首页和生成中的头像会转向窗口内的鼠标。默认按用户最新参考图呈现两只等大、竖直、略偏右的眼睛（SVG 中心位置为 45/59、41），独立于转头透视计算；鼠标正对头像时，两只眼睛等大、对称。转向时使用同一面部平面的透视投影，近眼略大、远眼略小，间距与朝向一起变化；最大水平转角为左右 30°，垂直转角为上下 10°，避免贴近脸部边缘或缩成细缝。按窗口边缘的实际可用距离计算转向，左侧的小头像也能向左看。每只眼睛独立眨眼并保留平滑过渡。鼠标离开窗口、窗口失焦或页面隐藏时回到参考姿态，触摸与减少动态效果模式保持同一默认姿态。所有活跃头像共享一份指针监听，每帧至多更新一次；历史消息头像不注册监听。

## 交互

- 输入框：Enter 发送，Shift + Enter 换行；中文输入法确认候选词时不触发发送。上传中或内容为空时禁用发送，生成时显示停止按钮。
- 对话输入区随内容和窗口宽度调整高度，最高 180px，长文本通过内部滚动查看；首尾保留文字内边距，工具栏独立占位，不覆盖最后一行。占位文字简化为“输入消息…”。
- 输入框旁以「工具／自动」胶囊打开工具箱，按图标、名称、描述及配置状态展示 13 个已注册工具；选择可用工具填入示例，搜索未配置时可进入设置。Agent 自行决定调用哪些工具。
- 点击侧栏头像收起／展开，不另设折叠按钮，也不会切换对话。收起后为 76px 图标栏，保留新对话、主导航与设置入口；展开恢复历史对话。切换不卸载当前页面，不丢失正在输入的草稿，外观偏好保存在本机 localStorage。600px 以下窗口使用紧凑顶部导航并保留新对话的加号入口。
- 工具记录使用可展开的圆角卡片，分行展示名称、返回内容和「已返回／待确认／调用失败」状态；失败项使用独立图标及颜色。重新进入对话恢复最近一轮的持久化记录。
- 输入区不常驻显示发送快捷键说明；Enter、Shift+Enter 与中文输入法处理保持原有行为。
- 模型入口打开菜单，显示当前连接并提供「连接与设置」。当前产品只有一个已配置连接；这里不展示不存在的模型选项。
- 菜单支持方向键与 Enter，Esc 关闭并返回触发按钮；弹窗保留 Radix 的焦点约束与键盘操作，并在关闭后恢复焦点。
- 保存与提交期间显示处理状态，失败时显示可读信息。学习状态、记忆确认与提醒完成使用明确文字区分。
- Tab 导航保留按钮、菜单等控件的焦点轮廓；根据用户批注，对话输入框聚焦时不出现外围选中框。减少动态效果的系统设置会关闭过渡与装饰动画。

大圆角及本轮配色是用户确认的项目局部选择。没有修改共享 QinBai 设计系统母版；模型、课程、记忆和提醒继续使用原有接口与数据结构。

头像最终采用用户确认的平面 A 版；此前的印记、小芽和高光立体方案不再用于实际界面。

## 开发缓存

迁移后的旧 `src-tauri/target` 含原路径生成信息。仓库通过 `.cargo/config.toml` 将新的开发构建缓存放在 `.local-data/cargo-ui-review`，启动器使用对应的可执行文件；此缓存不进入 Git。它与 `.local-data/dev`、隔离验证数据库分别存放。
